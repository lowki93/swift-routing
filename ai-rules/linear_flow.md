# Linear Flow (SwiftRouting)

This file defines the workflow to follow when working on a Linear ticket.

## Workflow

1. **Read the ticket** — fetch title, description, labels via the Linear MCP
2. **Explore the code** before making any changes
3. **Plan** — see `ai-rules/planning.md` for how to draft and get approval on the implementation plan
4. **Version control** — see `ai-rules/versionning.md` for the full pull/branch/commit/push/PR process and conventions

> Ticket states are updated automatically via the Linear ↔ GitHub integration.
